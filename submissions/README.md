# Skill Submissions (Staging Area)

## Instructions

Put your existing skill folder here before you submit your pull request.

```text
submissions/
└── <your-skill-name>/
    ├── SKILL.md
    └── scripts/ (optional)
```

## Rules

1. Use lowercase letters and hyphens for folder names (for example: `git-commit-helper`).
2. Add a `SKILL.md` file in your folder.
3. Remove all passwords, private keys, and sensitive tokens from all files.
4. Open a pull request against the `main` branch.

After a moderator approves your pull request, automation moves your skill to the final directory in `skills/`.
